this project was started as a way to chat with people on school laptops while being hosted on affordable hardware with no subscription necessary. it was created to run on chromebooks and be hosted on raspberry pi sbcs. this is the first part of the Trojan Communications Pipline and  incase you couldn’t tell it’s a discord clone the rest of the apps will follow the same theme of copying other services with the intent of web hosting them for school computers

to run install all dependencies with npm and run the node js server (will run on port 3000) which can then be funneled through dns server (I use tailscale)
also make sure to setup your sql database with a secure password for obvious security reasons.
